# Evidence Package (Weeks 1-4)

This folder stores reproducible proof for weekly deliverables.

## Structure

- week1/
- week2/
- week3/
- week4/
- runtime_logs/

## Required Artifacts Per Week

1. One short demo video (`demo_weekX.mp4`)
2. At least 3 screenshots (`screenshots/`)
3. One command/output log (`logs/weekX.log`)
4. One result summary (`README.md` in each week folder)

## Runtime Logs

The application now writes runtime events to:

- `evidence/runtime_logs/app_events.log`

Use these logs as objective evidence for detection, registration, and runtime behavior.
